ACG homepage — project structure

Complete static website with 37 local routes: homepage, six main pages, 18 news
articles and 12 linked advisory profiles. Internal navigation stays local.
The official enquiry form remains external by prior user choice; email, LinkedIn
and third-party resources retain their genuine external destinations.

Current commands
- npm run content:import: imports the homepage and all additional source pages.
- node scripts/fetch-pages.mjs: refreshes six main-page and 18 article snapshots.
- node scripts/fetch-assets.mjs: downloads missing original image assets.
- npm run build: builds all local routes under dist/.
- npm run verify: validates original content, assets, routes and anchor targets.
- npm run dev: serves directory routes at http://localhost:4173/.
- node scripts/browser-pages-qa.mjs: checks all routes at three viewport widths.

Current layout system (refinement pass)
- Shared 1312px container, 12 desktop columns, 32px gutters.
- Repeated 5/7 split across Why, Challenge and Mission; inverse 7/5 for the hero.
- Responsive section spacing 96/80/64px and major group spacing 48/40/32px.
- Source composition remains in scripts/import-content.mjs; all visual spacing
  tokens and responsive grid rules remain in src/styles/site.css.
