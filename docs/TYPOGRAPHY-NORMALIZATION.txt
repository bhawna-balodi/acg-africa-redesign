Nearest multiples of 4px are used; exact half-way values round upward to retain
emphasis/readability. Fluid curves and existing breakpoint logic are retained
using CSS round(nearest, clamp(...), 4px). A fluid value can round downward by
less than 2px at an intermediate viewport; no smaller display scale is imposed.
For example, 768px hero accent 61.44 → 60px follows the explicit nearest rule.
At 390px it is 54.6 → 56px, and at 320px it remains 48px.

Architecture and roles
src/styles/typography.css owns the final semantic role tokens/mappings. It is
concatenated into the existing banners.css build output: no added DOM node or
stylesheet request, no font installation, and no runtime JavaScript changes.
Role selectors use existing classes and context, rather than assigning one
universal style to a heading tag. Page titles retain the existing 88px cap;
long editorial titles retain their existing 52px cap. Compact directory names,
news cards, related stories, infographic numbers and UI labels remain distinct.
Main section statements share the homepage section token across page families.
Lead paragraphs, normal paragraphs and ordinary prose bullets share role rules;
structured processes, captions and conclusions keep their different purposes.
Typography weights, leading, tracking, 24px text rhythm and 720px reading width
are centralized. Existing source content, colour, imagery and layouts are kept.
